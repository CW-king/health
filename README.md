# 핏로그

운동과 식단을 기록하고, 쌓인 숫자를 근거로 조언을 돌려주는 개인 트레이닝 로그입니다.
설치형 웹앱(PWA)이라 휴대폰 홈 화면에 추가하면 앱처럼 열리고 인터넷 없이도 동작합니다.

## 기능

- **운동 기록** — 운동 77종 내장. 세트별 무게·횟수, 유산소 시간·거리, RPE, 메모.
  입력하는 동안 볼륨과 추정 1RM이 실시간으로 계산됩니다. 지난 세션을 통째로 불러올 수 있습니다.
- **식단 기록** — 한식 위주 음식 129종 내장. 끼니별로 칼로리와 탄단지가 집계되고,
  목록에 없는 음식은 직접 입력합니다.
- **자동 목표 계산** — Mifflin-St Jeor 공식으로 기초대사량을 구하고 활동계수와 감량·증량 목표를 반영해
  하루 칼로리와 탄단지 목표를 정합니다.
- **리뷰와 조언** — 최근 7·14·30일을 분석해 100점 만점 점수와 항목별 코칭을 보여줍니다.
- **체중 추세** — 4주 선형 회귀로 주당 증감 속도를 계산해 목표 속도와 비교합니다.

## 조언이 판단하는 기준

| 항목 | 기준 |
|---|---|
| 칼로리 | 목표 대비 ±7% 안이면 적정, 초과·미달 폭에 따라 경고 |
| 단백질 | 체중 1kg당 설정값(기본 1.8g), 15% 이상 미달이면 경고 |
| 부위별 볼륨 | 주당 직접 세트 8~22세트 |
| 밀기 : 당기기 | 1 : 1, 밀기가 1.8배를 넘으면 경고 |
| 주간 볼륨 증가 | 30% 초과 급증은 부상 위험 신호 |
| 유산소 | 주 150분 |
| 감량 속도 | 주당 체중의 0.5~1.0% |

의학적 진단이 아닙니다. 통증이나 질환이 있다면 전문가와 상의하세요.

## 휴대폰에서 쓰기

1. 저장소 **Settings → Pages → Source**를 `GitHub Actions`로 바꿉니다.
2. `main` 또는 작업 브랜치에 푸시하면 배포되고 `https://<계정>.github.io/health/` 주소가 생깁니다.
   (Actions 탭에서 `Deploy to GitHub Pages`를 직접 실행해도 됩니다.)
3. 휴대폰에서 그 주소를 열고 홈 화면에 추가합니다.
   - 아이폰(Safari): 공유 버튼 → 홈 화면에 추가
   - 안드로이드(Chrome): ⋮ → 홈 화면에 추가

## 로컬에서 실행

빌드 도구가 없습니다. 정적 서버만 있으면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 직접 열면 ES 모듈과 서비스 워커가 막히니 반드시 서버로 여세요.

## 데이터

모든 기록은 브라우저의 `localStorage`에만 저장됩니다. 서버로 전송되지 않고 계정도 없습니다.
브라우저 데이터를 지우거나 기기를 바꾸면 사라지므로 **더보기 → 파일로 내보내기**로 가끔 백업하세요.
같은 화면의 가져오기로 복원합니다.

## 구조

```
index.html            앱 셸 (상단바 · 뷰 · 하단 탭)
css/app.css           디자인 토큰과 컴포넌트, 라이트/다크 대응
js/app.js             해시 라우터
js/store.js           localStorage 저장소, 목표 계산, 집계 질의
js/advice.js          규칙 기반 조언 엔진과 주간 점수
js/charts.js          인라인 SVG 차트 (링 · 막대 · 꺾은선)
js/data/              운동 · 음식 사전
js/views/             오늘 · 운동 · 식단 · 리뷰 · 더보기
sw.js                 오프라인 캐시
```

영양 성분은 일반적인 식품성분표 기준의 근사치이며 조리법에 따라 달라집니다.

# 눈보라 벌목장 (`game/`)

같은 저장소에 들어 있는 별도의 웹 게임입니다. 화이트아웃 서바이벌 광고 · 피자레디 류의 방치형 타이쿤으로,
나무를 베어 팔고 번 돈으로 캠프를 키우되, 꾸준히 방어를 올리지 않으면 북극곰 습격에 캠프가 무너집니다.

- **플레이** 배포 주소 뒤에 `game/`을 붙입니다. 예: `https://<계정>.github.io/health/game/`
  휴대폰에서 홈 화면에 추가하면 전체 화면 앱처럼 열립니다. (조이스틱: 화면 드래그 / PC: WASD·방향키)
- **자동 저장** 3초마다, 그리고 화면을 벗어날 때 `localStorage`에 저장됩니다. 돌아오면 벌목꾼이 자리를 비운 동안(최대 2시간) 번 돈을 줍니다.
- **끝없는 진행** 도끼·가방·가격·홍보·울타리·무기·감시탑은 상한 없이 올릴 수 있고, 웨이브는 계속 강해집니다.
  3의 배수 웨이브엔 늑대 무리, 10의 배수 웨이브엔 설인 보스. 캠프가 무너지면 격퇴한 웨이브 3회마다 눈송이 1개를 받고,
  눈송이 1개당 다음 판 수입이 영구히 +3%입니다.
- **밸런스 수정** `game/config.js`의 숫자만 바꾸면 됩니다 (가격, 습격 주기, 곰 체력 성장률, 업그레이드 비용 등).

```
game/index.html   화면 뼈대(캔버스 + HUD)
game/config.js    밸런스 수치와 업그레이드 정의
game/sim.js       게임 로직 (화면 없이도 동작 → 밸런스 시뮬레이션 가능)
game/render.js    캔버스 그리기
game/audio.js     WebAudio 합성 효과음
game/main.js      입력 · 카메라 · HUD · 저장 · 모달
```
