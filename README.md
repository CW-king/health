# 핏로그

운동과 식단을 기록하고, 쌓인 숫자를 근거로 조언을 돌려주는 개인 트레이닝 로그입니다.
설치형 웹앱(PWA)이라 휴대폰 홈 화면에 추가하면 앱처럼 열리고 인터넷 없이도 동작합니다.

## 기능

- **운동 기록** — 운동 77종 내장. 세트별 무게·횟수, 유산소 시간·거리, RPE, 메모.
  입력하는 동안 볼륨과 추정 1RM이 실시간으로 계산됩니다. 지난 세션을 통째로 불러올 수 있습니다.
- **식단 기록** — 한식 위주 음식 129종 내장. 끼니별로 칼로리와 탄단지가 집계되고,
  목록에 없는 음식은 직접 입력합니다.
- **자동 목표 계산** — Mifflin-St Jeor 공식으로 기초대사량을 구하고 활동계수와 감량·증량 목표를 반영해
  하루 칼로리와 탄단지 목표를 정합니다.
- **리뷰와 조언** — 최근 7·14·30일을 분석해 100점 만점 점수와 항목별 코칭을 보여줍니다.
- **체중 추세** — 4주 선형 회귀로 주당 증감 속도를 계산해 목표 속도와 비교합니다.

## 조언이 판단하는 기준

| 항목 | 기준 |
|---|---|
| 칼로리 | 목표 대비 ±7% 안이면 적정, 초과·미달 폭에 따라 경고 |
| 단백질 | 체중 1kg당 설정값(기본 1.8g), 15% 이상 미달이면 경고 |
| 부위별 볼륨 | 주당 직접 세트 8~22세트 |
| 밀기 : 당기기 | 1 : 1, 밀기가 1.8배를 넘으면 경고 |
| 주간 볼륨 증가 | 30% 초과 급증은 부상 위험 신호 |
| 유산소 | 주 150분 |
| 감량 속도 | 주당 체중의 0.5~1.0% |

의학적 진단이 아닙니다. 통증이나 질환이 있다면 전문가와 상의하세요.

## 휴대폰에서 쓰기

1. 저장소 **Settings → Pages → Source**를 `GitHub Actions`로 바꿉니다.
2. `main` 또는 작업 브랜치에 푸시하면 배포되고 `https://<계정>.github.io/health/` 주소가 생깁니다.
   (Actions 탭에서 `Deploy to GitHub Pages`를 직접 실행해도 됩니다.)
3. 휴대폰에서 그 주소를 열고 홈 화면에 추가합니다.
   - 아이폰(Safari): 공유 버튼 → 홈 화면에 추가
   - 안드로이드(Chrome): ⋮ → 홈 화면에 추가

## 로컬에서 실행

빌드 도구가 없습니다. 정적 서버만 있으면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 직접 열면 ES 모듈과 서비스 워커가 막히니 반드시 서버로 여세요.

## 데이터

모든 기록은 브라우저의 `localStorage`에만 저장됩니다. 서버로 전송되지 않고 계정도 없습니다.
브라우저 데이터를 지우거나 기기를 바꾸면 사라지므로 **더보기 → 파일로 내보내기**로 가끔 백업하세요.
같은 화면의 가져오기로 복원합니다.

## 구조

```
index.html            앱 셸 (상단바 · 뷰 · 하단 탭)
css/app.css           디자인 토큰과 컴포넌트, 라이트/다크 대응
js/app.js             해시 라우터
js/store.js           localStorage 저장소, 목표 계산, 집계 질의
js/advice.js          규칙 기반 조언 엔진과 주간 점수
js/charts.js          인라인 SVG 차트 (링 · 막대 · 꺾은선)
js/data/              운동 · 음식 사전
js/views/             오늘 · 운동 · 식단 · 리뷰 · 더보기
sw.js                 오프라인 캐시
```

영양 성분은 일반적인 식품성분표 기준의 근사치이며 조리법에 따라 달라집니다.

# 눈보라 벌목장 (`game/`)

같은 저장소에 들어 있는 별도의 웹 게임입니다. 화이트아웃 서바이벌 광고 · 피자레디 류의 방치형 타이쿤으로,
나무를 베어 팔고 번 돈으로 마을을 키우되, 꾸준히 방어를 올리지 않으면 북극곰 습격에 본부가 무너집니다.

- **플레이** 배포 주소 뒤에 `game/`을 붙입니다. 예: `https://<계정>.github.io/health/game/`
  휴대폰에서 홈 화면에 추가하면 전체 화면 앱처럼 열립니다. (조이스틱: 화면 드래그 / PC: WASD·방향키, F·스페이스: 사냥 추적)
- **자동 저장** 3초마다, 그리고 화면을 벗어날 때 `localStorage`에 저장됩니다. 돌아오면 일꾼들이 자리를 비운 동안(최대 2시간) 번 돈을 줍니다.
- **넓은 맵** 왼쪽 위 숲, 맨 위 강(낚시터), 오른쪽 위 사냥터, 가운데 가게 거리, 왼쪽 아래 캠프, 아래쪽 공방과 마트, 남쪽 황무지(습격이 오는 곳).
  업그레이드 결제 원은 그 행동이 일어나는 자리 옆에 있고, 왼쪽 위 미니맵으로 위치를 봅니다.
- **끝없는 진행** 목재 판매대 → 정육점(곰 사냥) → 어물전(강 낚시) → 가구 공방(의자 → 소파 → 침대 → 옷장 → 피아노) → 마트(묶음 구매 ×1.3)
  → 마을 회관(개척지 → 마을 → 큰 마을 → 읍내 → 도시) · 마을 방위대 · 봉화대. 수치 업그레이드는 상한이 없습니다.
- **마트 이후** 판매대·정육점·어물전·모피 상점은 마트로 합쳐져 사라지고, 빈 자리에 🍲 식당(생선·고기 요리), 🧵 재단소(모피 옷),
  🏨 여관(공방의 침대·의자로 객실), 🚢 무역 부두(3분마다 무역선이 마트 재고를 1.6배에 대량 매입)가 들어섭니다.
  마트는 계산대(최대 5줄)·품목 확장(가구·요리·의복)·묶음 구매로 키우고, 손님은 없는 품목은 빼고 있는 만큼 삽니다.
- **고기·모피** 목장(순록) → 도축장 → 정육점, 사냥터(곰) → 모피 상점. 모피는 사냥터 곰, 습격 온 곰·늑대·설인의 전리품,
  🧶 무두질(도축한 순록 한 마리당 모피)에서 나오고, 🗡️ 가죽 손질(마리당 +1)·🐟 미끼(한 번에 여러 마리)로 사냥터 생산을 늘립니다.
  사냥꾼은 사냥터의 모피·고기를 직접 챙겨 가죽 더미·고기 걸이(또는 가게)에 두고, 🧺 수거꾼은 더미와 맵 전체의 전리품을 실어 나르며(🛷 썰매) 습격 경보가 울리면 캠프 옆 초소에서 대기합니다.
- **수급 현황** 위쪽 📊 버튼: 품목별 분당 생산·소비, 가게 재고, 더미에 쌓인 양과 상태(생산 부족·운반 지연·과잉)에 맞는 추천 업그레이드.
  같은 문제가 90초 넘게 이어지면 새 소식으로도 알려 줍니다. 수거꾼은 가게에 모자란 비싼 물건부터 나릅니다.
- **운반 분업** 수거꾼이 2명 이상이면 📦 운반 분업을 열 수 있습니다. 1단계 사냥꾼·도축업자, 2단계 어부·양식업자, 3단계 벌목꾼이
  자리에서 일만 하고 더미(가죽 더미·생선 바구니·통나무 더미·도축장 보관함)에 쌓으면 수거꾼(최대 8명, 썰매 5단계)이 실어 나릅니다.
- **방어** 감시탑은 캠프 남문 앞, 습격이 오는 길목에 서 있습니다. 경비병은 각자 한 마리씩 맡아 싸우고 잡으면 다음 적으로 옮깁니다(보스에는 여럿이 붙습니다).
- **양식장 · 남쪽 숲** 식당 이후 강 왼쪽에 🐠 양식장(가두리, 양식업자가 건져 나름, 어분 사료)을, 공방 옆에 🌲 남쪽 숲(벌목지)을 열 수 있습니다.
- **습격** 3의 배수 웨이브엔 늑대 무리, 10의 배수 웨이브엔 보스(설인 → 설인 전사 → 설인 왕 → 고대 설인 → 얼음 거인, 체력 35% 이하 분노).
  적은 경비병과 플레이어도 공격해 쓰러뜨립니다. 울타리는 나무 울타리 → 통나무 목책 → 돌담 → 성벽, 본부는 오두막 → 요새,
  감시탑은 망루 → 감시탑 → 석탑(화살 1 → 3발)으로 외형이 바뀝니다.
- **감시탑 내구도 · 수리** 감시탑은 6레벨마다 한 기씩 늘고(최대 4) 쇠뇌·대포·소총·기관총으로 바뀌며, 적은 지나가며 탑을 부수고 보스는 탑부터 노립니다.
  부서진 탑은 쏘지 못하므로 🔧 수리(본부 왼쪽 원)로 고치거나 🔨 수리공을 두면 탑·본부·울타리를 알아서 고칩니다. 쓰러진 경비병은 30초 안에 치료(의무병·플레이어)받지 못하면 전사해 경비병 레벨이 깎입니다.
- **개척지** 세계는 동쪽으로 계속 넓어집니다. 🧭 동쪽 벌판(훈제장·육가공소 + 🌱 묘목장(산림꾼이 나무를 심고 베어 목재) · 🥛 낙농장(목장 3레벨 뒤, 낙농꾼이 젖을 짜 우유) · 🧀 유제품 공방)
  → ⛏️ 광산 골짜기(광부가 광석 채굴, ⚒️ 대장간: 광석+목재 → 철물·연장·갑옷·태엽, 💎 보석 세공소: 귀족·왕족이 찾는 반지·목걸이·왕관)
  → 🌾 평원 농장(농부가 씨를 뿌리고 거두는 밀밭, 🍞 빵집: 곡물+우유 → 빵·파이·케이크, 🍺 양조장: 맥주·벌꿀술·위스키). 마트 품목 확장은 10단계까지 늘어 새 상품도 마트에서 팝니다.
  농장류는 모두 같은 구조(자리가 자라면 일꾼이 거둬 더미·가게로 나름)라 `config.js`의 `farms`에 항목을 더해 새 작물을 쉽게 넣을 수 있습니다.
- **날씨** 동쪽 개척 뒤 날씨가 바뀝니다. ☀️ 맑음(손님·성장 +15%) · ❄️ 눈보라(이동·적 속도 −20%, 손님 −30%, 성장 −40%) · 🌫️ 안개(광산 뒤, 탑 사거리 −30%)
  · 🌌 오로라(판매가 +20%) · 🌤️ 해빙(농장 뒤, 작물 성장 +60%). 위쪽 ❄ 줄과 📊 창에 표시되고, 화면에도 눈보라·안개·오로라가 그려집니다.
- **손님 계급 · 주문 게시판** 마을이 커지면 마을 사람 → 나그네 → 상인 → 귀족 → 왕족이 섞여 오고(평판에 따라), 귀족·왕족은 비싼 제작품·보석을 더 찾습니다.
  📜 주문 게시판(회관 왼쪽)을 세우면 상인·귀족·왕족이 대량 주문을 내고, 마트(또는 만드는 가게) 재고에서 1초에 1개씩 채워져 기한 안에 다 채우면 가격의 1.5~1.9배 보상과 평판을 줍니다.
- **성능** 사람·글자 그리기는 한 번 그린 이미지를 재사용하고(스프라이트 캐시), 프레임이 느려지면 해상도를 자동으로 낮춥니다. 후반에 직원·손님이 200명 가까이 있어도 60fps를 유지합니다.
- **눈송이** 본부가 무너지면 격퇴한 웨이브 3회마다 눈송이 1개. 눈송이 1개당 다음 판 수입이 영구히 +3%입니다.
- **내 그림으로 바꾸기** 캐릭터는 코드로 그리지만, `game/assets/`에 스프라이트 시트 PNG를 넣고 `sprites.json`에 파일명을 적으면
  그 이미지를 대신 씁니다. 자세한 방법은 `game/assets/README.md`를 보세요.
- **밸런스 수정** `game/config.js`의 숫자만 바꾸면 됩니다 (가격, 습격 주기, 곰 체력 성장률, 업그레이드 비용, 위치 등).

```
game/index.html   화면 뼈대(캔버스 + HUD)
game/config.js    밸런스 수치, 지도 배치, 업그레이드·적·외형 단계 정의
game/sim.js       게임 로직 (화면 없이도 동작 → Node로 밸런스 시뮬레이션 가능)
game/render.js    캔버스 그리기
game/audio.js     WebAudio 합성 효과음
game/sprites.js   이미지 스프라이트 로더 (assets/sprites.json)
game/main.js      입력 · 카메라 · HUD · 저장 · 모달
```
